# UG1FOW – Web Development Practicals

## 📚 About This Repository

This repository contains a collection of **Web Development practicals** completed as part of the **UG1FOW** course.

The practicals are organized using **practical numbers** for easy identification and reference. Some practicals use **HTML**, while others include **CSS** for styling and page design.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript *(where applicable)*

## 📂 Practical Files

The repository contains practicals organized by number, for example:

```text
UG1FOW/
│
├── Practical-01/
├── Practical-02/
├── Practical-03/
├── Practical-04/
├── Practical-05/
├── Practical-06/
├── ...
└── README.md
```

Each practical may contain one or more HTML/CSS files and supporting resources such as images.

## 🎯 Learning Objectives

These practicals are designed to provide hands-on experience with:

* Creating HTML webpages
* Working with HTML elements and attributes
* Creating forms and tables
* Designing page layouts
* Applying CSS styles
* Working with external, internal, and inline CSS
* Creating navigation between webpages
* Organizing website files and resources
* Using Git and GitHub for version control

## ▶️ How to Run a Practical

1. Clone or download this repository.
2. Open the required practical folder.
3. Open the `.html` file in a web browser.

For example:

```text
Practical-01/
└── practical1.html
```

Open `practical1.html` in Chrome, Edge, Firefox, or another modern web browser.

If a practical contains CSS, make sure the CSS file remains in the correct location relative to the HTML file.
